# 验收

维护者运行 `python -m unittest discover -s scripts -p test_booktool.py -v` 和 `node scripts/test_state.cjs`。前者检查格式提取、台账恢复、核对绑定、逐条出处与批量失败；后者是页面状态/渲染模拟，不是浏览器视觉测试。

生成 examples，实际打开 HTML，五主题分别检查 390/768/1440，320 加长书名。检查溢出、弹窗、Tab/Escape、减少动态效果、开始→继续、两个读完分别计数、刷新保存、专用测试记录导入导出。不要清空用户真实记录。

同页两条远距离引用必须分别显示自己的原文；梗概依据也要在其短上下文中。剧透书把特征词放进简介、覆盖、图题、短句、路线，打开前所有正文区域不可见，确认后可见。刷新应重新出现剧透确认。

缺执行工具时实际交付文字版，缺解析器时解释具体缺项；一批文件中一本损坏时其余结果继续。扫描页、真实 MOBI、Windows/Linux、其他浏览器各自记录实测状态。

# 流程与实际能力

| 阶段 | 调用能力 | 没有时 |
|---|---|---|
| 接收文件 | 宿主附件/文件读取 | 邀请提供可读文本或章节 |
| 格式检查与提取 | booktool preflight/extract；PDF 可选解析器；EPUB 标准库；MOBI 可选 Calibre | 提供转换路径，或先交付可读部分；不自动安装系统软件 |
| 分章阅读与内容整理 | 宿主模型、reading.json 台账 | 保存未完成状态，继续时从记录接续 |
| 内容与出处核对 | 宿主语义回看 + 脚本逐字依据/摘要/覆盖校验 | 未核对不能称已核实的完整网页 |
| 页面呈现 | 随包 HTML/CSS/JS + Python 生成器 | MD 与文本脑图 |
| 设计增强 | 随包五主题和手绘框；可选已安装设计 Skill | 默认规则仍可用 |
| 可视验收 | 宿主浏览器工具或真实人工打开 | 明确未视觉验收，不把代码通过当页面通过 |
| 保存记录 | 读者浏览器 localStorage | 本次内存记录可导出；不保证跨端同步 |

| PDF 阅读与标注 | 随包 PDF.js、浏览器文本选择、IndexedDB | file 协议提示启动本机服务；无文字层先 OCR；其他格式看导览 |
| 摘录联动与备份 | 同一标注记录、时间倒序、JSON 合并与回滚 | 存储不可用时说明失败，不冒充已保存 |

平台负责哪一段需实际验证。不能把 REDSkill 获取入口、AI 助手生成环境、交付网页混成同一服务。

完整交付时保留 reader/pdfjs 与 start_reader.py。详细过程见 [PDF 操作说明](../docs/pdf-annotations.md)。

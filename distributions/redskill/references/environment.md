# 环境检测与降级

| 能力 | 正常 | 缺失时 |
|---|---|---|
| 文件与执行工具 | 运行随包脚本 | 用宿主解析，先交付 MD；说明不能自动写网页 |
| Python 3.9+ | 标准库脚本 | 先找宿主自带运行时，再引导 python.org；Windows 可尝试 py -3；不接受系统许可或改系统 Python |
| TXT/MD | UTF-8 / GB18030 | 解码失败请另存 UTF-8，不吞乱码 |
| EPUB | ZIP/XML 按 spine 读取 | 加密、损坏、超限明确报错；请提供可读 EPUB/TXT/MD |
| PDF | PyMuPDF / pypdf / pdftotext 之一 | 宿主解析替代，或隔离环境安装 pypdf，或提供文字版 |
| 扫描页/图片文字 | 已配置 OCR 或宿主视觉 | 本包不内置 OCR；核对空字页，说明缺页或换文字版 |
| MOBI | PATH 中 Calibre ebook-convert 转 EPUB | 引导 calibre-ebook.com/download 或另存 EPUB；不处理 DRM |
| 模型 | 宿主分章分析 | 保存材料与覆盖记录等待恢复，不能从脚本生成假的摘要 |
| 设计 Skill | 存在则按需使用 | 内置基础内容与设计规则；不必安装所有 Skill |
| 图像工具 | 可选场景插画 | 内置手绘结构图照常呈现 |
| 浏览器工具 | 截图与交互验收 | 静态校验继续，明确未可视验收 |
| 浏览器存储 | 自动保存 | 提示仅本次有效，可导出记录；不能显示假保存成功 |

preflight 仅检查当前命令环境；模型权限、额度、浏览器能力由宿主核验。macOS/Windows/Linux 共用脚本，实际跨平台能力须分别验证。移动端可看网页，不承诺运行转换。MOBI 的 Calibre 可能未加入 PATH，应配置实际工具路径再重试。

只为缺项提供官方来源和具体下一步，不一次要求全装。安装涉及网络、改变环境时说明范围，优先隔离环境。不得自动安装系统级软件。生成会由宿主模型处理正文，本地提取不等于模型分析完全离线。

交付检查：能运行脚本不等于能把文件交到用户手里。生成后确认可下载/可访问；受限预览工具拒绝打开时，不绕过其限制，交付用户可自行打开的文件及 MD。REDSkill 实际运行宿主与分发路径待平台实测。

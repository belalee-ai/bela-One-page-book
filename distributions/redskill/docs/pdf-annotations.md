# 原书划线、笔记和摘录怎么用

0.3 支持 PDF、EPUB、MOBI、TXT、Markdown。文字导览仍可以直接双击 HTML 打开；想在原书上划线，需要保留生成的整个文件夹，再启动本地阅读服务。0.2 的 PDF 标注依然可用。

## 先看效果

![原文高亮、笔记、首次标注日期和自动保存状态](images/pdf-annotation-note.png)

这是 0.2 便携版的实际截图，拍摄于 2026-09-22。书和笔记均为公开演示材料。左侧是选文后的重点标记；右侧可以记笔记、切换划线或重点，并看到标注日期和保存状态。返回导览后，可在“我的摘录与笔记”中继续查看同一条记录。

## 第一次打开

让助手帮你完成这一段即可：

> 请生成一页读书网页，并启动交付目录里的 start_reader.py。告诉我浏览器地址。我想在原书里划线、写笔记，并且下次打开仍能看到。

自己操作时，在生成的网页目录打开终端：

```sh
python start_reader.py
```

Windows 没有 `python` 命令时可用 `py -3 start_reader.py`。浏览器打开 [本机阅读地址](http://127.0.0.1:8880/)。保留启动窗口；以后仍使用同一个地址和浏览器用户资料。不要为了打开 PDF 关闭浏览器的安全保护。

在导览上点“添加这本原书”，选择生成这份导览时用的**同一份文件**。PDF 保留原页序；EPUB、MOBI、TXT 和 Markdown 提取为分节文字阅读版，不保留插图和原版式。首次或换浏览器后需要再添加。选错书或不同版本时会提示，避免把笔记放到别的书上。

## 怎么划线

1. 点“打开原书”，拖选一段文字。
2. 点“划线”“重点”或“笔记”。只选中文字不会自动保存标注。
3. 写好笔记后自动保存；保存失败时页面会提示重试。
4. “本书标注”按页或分节顺序集中展示；可修改、移除和撤销刚才的移除。
5. 返回导览，在“我的摘录与笔记”回看自己的内容，点“回到原文”定位到页或分节和标记。

摘录默认显示最近 4 条，可以展开全部或收起。按最近修改时间从新到旧排列，但卡片只显示首次标注日期，之后改笔记也不会改变它。马蒂斯主题的回原文按钮是淡紫底、深紫字；其他主题跟随各自配色。工具条、划线和面板有柔和过渡，减少动态效果时自动简化。

## 下次还在吗

正常情况下在。PDF 与文字阅读版、标注存在此浏览器的 IndexedDB，进度保存在 localStorage，原书文件不会被修改。文字书会交给仅在 `127.0.0.1` 运行的阅读服务提取，服务不保存副本；它不是云端上传。没有账号，也没有云端同步。换端口、换浏览器、清除网站数据或使用无痕模式，都可能看不到以前的记录。

不需要每天点保存。需要备份时点“导出进度与标注”。换浏览器后，重新添加同一份原书，再“导入进度与标注”。备份不包含原书或导览正文，请另保留书和整个网页目录。

0.1 便携版的阅读进度 JSON 可以导入，已有标注不会被清空。新备份会合并较新的标注，旧备份不会复活已删除的标注。笔记过多导致备份超过 16 MB 时会拒绝导入并说明原因，建议保留完整浏览器资料并联系维护者分批迁移。

作者本地书架服务的 v4 备份是另一种格式，请在原本地书架恢复；不要把不同产品格式互相导入。更新 Skill 本身不会迁移或删除这些浏览器数据。

## 哪些情况暂时不能划线

- PDF 超过 100 MB、有密码、损坏或没有可选择文字：先分卷、解密或识别文字。
- EPUB、MOBI、TXT、Markdown 单文件超过 60 MB：文字阅读器会拒绝添加；请让助手分卷整理并分别生成导览。
- EPUB/MOBI 有加密、文字藏在图片里或无法解码：先换可读版本；部分 MOBI 可用 Calibre 转换。扫描版 PDF 需先 OCR。
- 只打开一个 HTML 文件、缺少 `reader` 或 `ebook_import.py`：导览仍可读，原书阅读和标注需要完整目录与本地启动。
- 宿主只能生成文字、不能运行程序：交付 Markdown；不要给用户一个打不开的假网页链接。
- 平台内嵌浏览器、Safari、手机触屏：未完成全链路实测，优先桌面 Chrome / Edge。提示不支持时继续读导览或在系统阅读器打开原书。

PDF.js 的现代构建依赖较新的浏览器能力，官方也说明本地文件访问存在浏览器限制：[官方说明](https://github.com/mozilla/pdf.js/blob/master/README.md)、[支持范围](https://github.com/mozilla/pdf.js/wiki/Frequently-Asked-Questions)。本包固定 PDF.js 6.2.108，并保留许可证，不需要用户临时联网下载组件。

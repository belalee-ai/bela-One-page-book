# bela-One-page-book · 一页读书

把想读的厚书，变成有出处的梗概、脑图、短摘录和阅读路线。

欢迎来到一页读书。这是留给你的一点时间，在繁忙中找到片刻闲暇。

## 使用

下载仓库后，将整个文件夹命名为 `bela-one-page-book`，放入助手支持的 Skill 目录。重新打开任务，输入：

> 使用 $bela-one-page-book，把这本书做成一页读书。

附上 PDF、EPUB、TXT 或 MD；MOBI 需要 Calibre，扫描书需要 OCR。环境缺项时先检测并提供替代路线，不要求安装全部设计 Skill。

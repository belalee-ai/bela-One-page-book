# 如何测试

## 1. 浏览器视觉和交互

生成 examples 的网页，用 Chrome 手动打开 demo/index.html；如果代理浏览器禁止 file 地址，不绕过限制，由用户正常打开并反馈。另在 Safari/Edge 用相同样例复核。

每个主题检查 320/390/768/1440 宽度：长书名不截断、没有横向滚动、手绘框不压字、出处按钮可点；展开脑图、关闭来源弹窗、切换书和主题，再刷新确认记录。使用键盘 Tab/Enter/Escape，启用系统减少动态效果，确认仍可操作。

阅读记录验收：开始→继续；导览读完与原书读完分别计数；导出备份，在专用测试浏览器导入，验证状态一致。拒绝损坏 JSON；禁止存储时应有提示且仍能导出。不得清除真实用户记录。

保存各宽度截图，记录浏览器/版本、主题、通过/失败和问题位置。自动状态测试不代替这一步。

## 2. Windows / Linux / macOS

GitHub Actions 的 Portable skill checks 提供三系统矩阵：运行环境检测、11 项 Python 测试、8 组状态检查和示例网页生成。日志变绿只说明这些检查通过，不等于桌面浏览器或所有 Python 版本已通过。

首次在真实电脑解压到含中文及空格的路径，按 INSTALL 运行；确认无需作者私人路径、无其他设计 Skill 也能生成。运行时缺失要验证提示而不是只测正常路径。

## 3. MOBI

找一本有权使用且无 DRM 的真实 MOBI，保留原文件；在安装 Calibre 的测试机运行 extract。检查转换后的章节顺序、前中后正文、中文标点、引文定位；与原书逐项对照，再走 guide.json→网页。补测缺 Calibre、加密文件、损坏文件，要求解释问题且其余书继续。

EPUB→MOBI→EPUB 的自产夹具只能检查转换链路，不能替代真实 MOBI。未跑这些步骤前保留“未实测”。OCR 另测扫描页，本包未内置。

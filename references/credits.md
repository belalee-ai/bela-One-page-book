# 来源、范围与致谢

本候选版基于作者现有 bela-one-page-book 的脚本、网页模板与说明修订；五主题 CSS 沿用现有实现。examples 是项目自写的两章验收短文，不是商业出版物。包内不含第三方插画、字体、图表库、外部 Skill 全文或真实用户书籍。

制作一页读书时，作者曾调用或参考 Hallmark、Apple Design、Humanizer-zh、Design Taste、Product Design Audit、skill-creator 的方法。谢谢这些创作者分享经验。此处记录制作过程中的帮助，不表示本版执行时必须安装或调用全部 Skill。

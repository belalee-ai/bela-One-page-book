# 书放进来以后，怎么读

还没安装？先看 [复制安装指令](../INSTALL.md)，选你正在使用的工具。

## 导入一本书

打开安装了本 Skill 的助手，在对话里添加书籍附件。你使用的助手如果能访问本地文件，也可以直接把文件路径给它。

> 使用 $bela-one-page-book，帮我读这本书。我想先了解全貌，再决定哪里值得细读。

不用自己先转格式，也不用把文件上传到 GitHub。当前分享版是在助手里生成，阅读网页没有“上传一本书后自动生成”的入口。

助手会检查是否能提取文字。PDF 页序和 EPUB 章节位置会保留，后面短句和节点的出处靠这些位置对应。需要转换工具时，只补当前缺的工具；读不到的页面应明确列出。

## 一次导入多本

把多个文件一起提供，说明先读哪一本。如果附件数量超过助手限制，可以分批发送。

> 这几本书先做《书名》。每本分别整理，完成后合成一个可以选书的网页。暂时处理不了的文件告诉我原因，其他的继续。

一次上传不等于一次就处理完全部内容。尤其是长书，助手可能分批阅读；中途停下时，保留工作目录，让它从已有覆盖记录继续。

## 生成完成后保存什么

| 文件 | 用来做什么 |
|---|---|
| `index.html` | 打开阅读页面 |
| `guide.md` | 单本的文字导览，用文本或笔记软件查看 |
| `books.json` | 已整理的页面内容，后面合并或重做网页时使用 |
| 原书文件 | 阅读完整正文、核对书摘 |

生成多书页面时，单本的 `guide.md` 仍留在各书输出目录。最省心的保存方式是保留整个输出文件夹。

后台可能还有 `book.md` 和 `source.json`。它们是从原书提取的工作材料，用于继续整理和核对，不必每天打开；也不要把含完整正文的工作目录当作 Skill 包公开上传。

打开环境建议：优先桌面 Chrome 或 Edge；系统、手机限制和记录保存说明见 [用什么系统和浏览器](../INSTALL.md#用什么系统和浏览器)。

## 打开后先做什么

1. 双击 `index.html`，或用浏览器“打开文件”选择它。
2. 如果里面有多本书，在顶部“选书”菜单挑一本。
3. 在“风格”里选你喜欢的颜色。默认莫兰迪，还可以换马蒂斯、旧书纸张、瑞士极简和夜读。
4. 点“开始读”，展开你感兴趣的梗概或脑图分支。

先看图，再读文字也可以。点击“查看出处 U…”会打开出处说明，里面是位置和短上下文；这不是原书完整阅读器。U 后面的数字只是材料编号，不用记住它。

有完整故事情节的书，梗概可能默认折叠并提示剧透；如果你不想知道结局，生成前就说“先别剧透”。

## 开始读、继续读和读完

首次点“开始读”后，页面会把这本书标为已开始，以后显示“继续读”。只有打开过网页、但没点开始，并不代表已经开始阅读。

“继续读”会定位到记录的展开栏目，不是精确恢复原书页码或你滚动到的每一个像素。

“导览读完了”记录这份梗概导览已经看完。“原书读完了”记录完整原书已看完，两者分开计数。点错时再次点击相应完成按钮，可以取消标记。

## 保存与备份

日常阅读无需点保存，页面会尝试自动写入当前浏览器。

换设备、换浏览器或更换网页文件前：

1. 在页面底部点“导出阅读记录”，保存下载的 JSON 文件。
2. 在新环境打开阅读网页，点“导入阅读记录”。
3. 选择这份备份，查看上方的已读数量和各书状态。

导入会合并记录，保留已有的完成标记。导入后想取消某本的完成状态，可在那本书的页面上取消。

备份中只有阅读记录，不包含原书或导览正文。请同时保留网页输出文件夹与原书。它不会自动把记录同步到另一台电脑。

无痕浏览、清理网站数据，以及本地文件地址变化可能影响保存。页面若提示无法持久保存，本次仍可以读，也可以导出记录；不要把它当成已经保存到磁盘。

## 后面再加一本书

把新书和旧的输出文件夹提供给助手，尤其保留旧的 `books.json`，然后说：

> 这是我原来的一页读书输出，再加入这本新书。旧导览保留，新书单独整理，最后给我一个能选择全部书的网页。

更新前先导出阅读记录，更新后用备份恢复。如果换了书籍文件版本，它可能被识别为另一本书，不保证自动继承旧版本状态。

## 想调整内容或样式

可以直接告诉助手你的具体感受：

> 梗概太短了，人物为什么做这个选择还没说清楚，请补上相关经历和出处。

> 我想把这本书的核心观点画成对照图，但不要编数据。

> 先用夜读风格，手机上标题小一点，正文别贴着边框。

五种主题是当前基础功能。增加人物插画、复杂信息图时，助手会检查可用工具与素材授权；没有额外设计 Skill，也能继续使用现有网页。

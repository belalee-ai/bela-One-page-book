# 0.2 更新与对抗检查

日期：2026-09-22。使用原创短文、原创 PDF 和专用测试记录；不把真实书籍或私人笔记放进发行包。

## 本次同步

- 分享版新增本地 PDF 阅读、划线、高亮、自动保存笔记、摘录联动、回原文定位。
- 摘录默认 4 条折叠，最近修改优先，只展示首次标注日期；马蒂斯回原文按钮为淡紫底深紫字。
- 沿用轻柔、可中断的面板和标注动效，尊重减少动态效果。
- GitHub 与 REDSkill 采用同一套 0.2 核心代码；REDSkill 分发仍是候选包，没有声称平台已审核或上架。
- 统一逐单元阅读、覆盖范围、证据窗口、语义核对记录与剧透门。0.1 的旧导览材料需按当前契约重新核对生成，不直接混入新书架；旧阅读进度仍支持恢复。

## 从“故意让它出错”开始检查

| 场景 | 发现或处理 | 验证 |
|---|---|---|
| 修改标注身份或首次日期 | 更新接口只允许笔记、样式、删除状态；身份与日期不一致拒绝 | Node 边界检查 + 浏览器导入拒绝 |
| 点另一条标注时笔记还没保存 | 切换前等待保存；失败时保留编辑区 | 代码修复；自动保存与恢复实测 |
| 不同书、相同标注编号、重复导入 | 文件摘要校验、身份隔离、按修改时间合并 | 浏览器隔离数据库检查 |
| 导入旧备份、导入后复活已删除记录 | 无标注旧包不清空现有记录；删除状态参与时间合并 | 浏览器隔离数据库 + 真实文件选择导入 |
| 进度写入失败但标注已写一半 | 同一导入事务失败则回滚 | 浏览器隔离数据库检查 |
| 页面换书多次 | 释放旧摘录监听，丢弃过期异步结果 | 实现核查，防止重复刷新与串页 |
| 用 `../` 越过静态资源目录 | 首轮测试复现，修复后拒绝；服务只监听本机并检查 Host | 6 项服务边界测试 |
| 阅读组件有已知漏洞 | 旧 5.6.205 落在影响版本范围，升级 6.2.108；显式关闭脚本执行 | 核对官方公告与 npm 完整性；升级后重新打开、翻页和恢复标注 |
| PDF.js 大版本接口变化 | 新版移除矩形转换接口，改为转换两个角点 | 实际复现并修复；缩放后标记对齐 |
| 缺工具、file 协议、无法持久保存 | 给出本地启动或文字版；备份读取标注失败时明确只导出进度 | 环境分支核查，非所有系统实测 |

安全来源：[GHSA-hq66-cqwq-w95j](https://github.com/advisories/GHSA-hq66-cqwq-w95j)。该公告说明影响条件与修复版本；这里没有运行恶意 PDF，也不宣称完成了渗透测试。npm 依赖审计在本次检查时未报告已知漏洞，这不等于保证无漏洞。

## 已经实际检查

- 本机 Python：32 项内容、提取、台账、证据与混合版本回归。
- Node：13 组状态/渲染约束、16 项标注边界检查。这些是逻辑检查，不是浏览器截图。
- 本机服务：6 项目录、路径、Host 和模块类型检查。
- 浏览器（macOS，Codex 内置 Chromium）：独立交付目录打开、添加原创 PDF、选文记笔记、自动保存、刷新恢复、首次日期、原文定位、升级后翻页与 1.5 倍缩放；6 条摘录折叠与倒序；真实 JSON 文件选择导入、错误指纹拒绝、旧备份保留现有标注。
- 浏览器隔离数据库：9 组真实 IndexedDB 写入、跨书隔离、合并、去重、删除和回滚检查，测试记录已清空。
- 五主题 × 390/768/1440 宽度：DOM 尺寸检查没有横向页面溢出；桌面阅读器实际画面检查通过。尺寸模拟不等于手机触屏真机验证。

- 两个发行包分别解压到独立目录，逐文件核对 SHA-256，并分别通过内容、状态、标注、服务边界和 PDF 示例生成检查。

## 仍然需要区分的状态

- Windows/Linux/macOS 的 CI 只证明脚本与生成检查；本轮 CI 结果以仓库 Actions 对应提交为准。
- Safari、Firefox、Edge、移动设备及各 Agent 的完整生成链路没有在本轮分别重测。
- REDSkill 上传后的审核、读者获取、客户端加载和运行链路仍待平台实测。包内包含 JS、Python、MJS、WASM；若平台不接受，使用 GitHub 安装入口或交付文字版，不把代码藏进 Markdown 绕过限制。
- 公开包没有作者私有书架生成服务、商业图书、私人路径和笔记；新增书籍仍通过宿主助手处理。
